# OCAN Energy and Projects Limited Website

Premium one-page corporate website for OCAN Energy and Projects Limited, prepared for `ocanenergy.com`.

## Files

- `index.html` - Complete website with embedded CSS and JavaScript.
- `favicon.svg` - Browser tab icon.
- `site.webmanifest` - Basic web app metadata.
- `robots.txt` - Search engine crawl rules.
- `sitemap.xml` - Sitemap template.

## Deployment

This is a static website. Upload the folder contents to any static host such as cPanel, Netlify, Vercel, GitHub Pages, Cloudflare Pages, or an S3-compatible host.

Before public launch, update:

- Verified office address, email, phone number, and social media links.
- The provided gallery placeholders with final project photos.
- Confirm whether the live domain is `ocanenergy.com` or `ocanenergy.com.ng`.
- Confirm whether `AkariOtu@ocanenergy.com.ng` is the final business email, since the website domain brief uses `.com`.

## Public Research Note

The website avoids fabricating company facts. Publicly available third-party profile snippets were used only for cautious industry context, while unverified official details are clearly marked in the page.
